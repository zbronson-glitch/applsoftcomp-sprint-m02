# Notes: 1d-data

## Dataset structure
This dataset contains a single quantitative measurement column (`value`) and a grouping label (`group`).

## Key observations
The values vary widely across samples, so a simple scatter plot makes the variation visible without implying continuity.

## Visualization strategy
I used a scatter plot with sample index on the x-axis and value on the y-axis. This keeps the plot simple and non-misleading while showing differences across subjects.
