# Notes: digits-data

## Dataset structure
This dataset contains 64 pixel features (`pixel_0` through `pixel_63`) and one label column (`digit`).

## Key observations
The dataset is high-dimensional, so a dimensionality reduction method is appropriate for visualization.

## Visualization strategy
I used t-SNE to project the 64-dimensional digit vectors into 2D, then colored points by digit label to show clustering patterns.
